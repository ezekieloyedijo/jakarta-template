⏳ Async demos

Slow jobs without blocking the server

Each demo takes a few seconds. Keep an eye on the terminal where Tomcat runs.

  • 1. Blocking servlet: a request thread waits 3 seconds doing nothing
  • 2. Async servlet: the same job on a worker thread; the request thread is free at once
  • 3. Timeout: the job takes 5 s but we only wait 2 s; an AsyncListener answers
  • 4. Async + dispatch: the worker hands the result to a JSP

The page looks the same to the user in demos 1 and 2: they still wait 3 seconds. The difference is inside the server: in demo 2, Tomcat's thread serves other people while the job runs.
