🗄️ Database and Listener demos

Talking to a database, and reacting to events

  • 1. Connect: open a JDBC connection and ask the database who it is
  • 2. Read and insert rows: SELECT with a ResultSet, INSERT with a PreparedStatement
  • 3. Visitors online: an HttpSessionListener counts the open sessions

The table fruit was created by StartupListener when the app started, before anyone opened a page. Look for [STARTUP] in the terminal. This demo database lives in memory, so it starts fresh every time Tomcat starts.
