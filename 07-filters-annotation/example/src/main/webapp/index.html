Filters: the guards at the door

Keep the terminal where Tomcat runs open: most filters write their messages there.

  • 1. A normal servlet: LogFilter and TimingFilter run around it
  • 2. A slow servlet: TimingFilter measures it (before and after)
  • 3. Blocked!: SecretKeyFilter stops requests without the key
  • 4. Let through: the same URL with the right key
  • 5. The filter chain: two filters, in the order set by web.xml

This page is a plain HTML file, but LogFilter (/*) still logged it. Filters see every request that matches their pattern, even for HTML and CSS files.
