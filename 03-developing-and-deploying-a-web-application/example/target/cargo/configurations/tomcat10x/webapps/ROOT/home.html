Topic 03: The Deployment Tour

You are looking at home.html, not index.html. Why? Because WEB-INF/web.xml lists home.html as the welcome file.

ClickWhat it proves
/classic A servlet with no annotation. It is registered in web.xml with <servlet> + <servlet-mapping>
/modern A servlet registered with the @WebServlet annotation. No XML needed
/settings A servlet reading context-param settings from web.xml
/WEB-INF/secret.html The file EXISTS, but WEB-INF is private, so you get a 404
/WEB-INF/web.xml The settings file is private too: 404
/no-such-page Our custom 404 page (configured in web.xml)
/boom A servlet that crashes. You see our custom 500 page, and the details go to the terminal log
