🍪 Session Tracking demos

Four ways to remember a user

  • 1. Hidden form fields: a 2-step form that carries your name in a hidden input
  • 2. URL rewriting: the language travels at the end of every link
  • 3. Cookies: a visit counter stored in your browser
  • 4. HttpSession: a visit counter stored on the server
  • 5. Ending a session: what "Log out" does

Every servlet here is registered with @WebServlet("/url") instead of web.xml entries. web.xml now only holds the session timeout.
